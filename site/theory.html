Theory: every equation next to its code

The code shown beside each equation is read from the running model with Python's inspect.getsource(), so it is exactly the code that produced the plots.

Assumptions

  1. 25 °C, ideal solutions (activity coefficients = 1). Kw = 1.0×10−14; acetic acid Ka = 1.75×10−5 (pKa 4.757).
  2. HCl and NaOH fully dissociated; acid–base reactions are instantaneous (equilibrium at every instant). Only mixing is dynamic.
  3. Each tank is a perfectly mixed CSTR with constant volume (overflow); volumes are additive, so outlet flow = inlet flow + reagent flow.
  4. Influent contains no sodium. Reagent is an NaOH solution (no heat of dilution).
  5. pH probe = first-order lag τm; transport dead time θ in the measurement path (rounded to whole time steps).
  6. Valve: delivered flow follows the controller output through a first-order lag τv, limited to [0, FR,max]; linear characteristic, no stiction.
  7. No CO2 exchange, no precipitation, no temperature effects.

State variables: reaction invariants

Per tank: a = total chloride, b = total sodium, w = total acetate (mol/L). Neutralization moves H+ around but cannot create or destroy Cl, Na or total acetate, so their balances are pure mixing balances with no reaction term. pH is then calculated from them (charge balance), not integrated — which removes the numerical stiffness that a [H+] balance would have near pH 7.

Why a valve lag?

A tank (1st order) plus a probe (1st order) under P-only control is a 2nd-order loop, which is stable for every Kc > 0 — Routh gives no upper limit. Real loops always have a third lag or dead time; the valve lag provides it in an exactly analyzable way. Set τv = 0 and θ = 0 in the tool and the stability limit becomes ∞.

Key result

The linearized tank is Gp(s) = Kp/(τs + 1) with τ = V/Q, and Kp is exactly the slope of the titration curve. With P-only control the Routh limit is Kc,u = (a1a2/a3 − 1)/Kp: the lags set the numerator and the chemistry sets the denominator. The stable gain range shrinks by exactly the factor the titration slope grows, while the oscillation period Pu = 2π√(a3/a1) does not change at all.
